# Bash Lab — Shell и Bash с нуля

Лаба по Shell и Bash: от терминала и первого скрипта до массивов, grep/sed/awk и деплой-скрипта. Сквозной проект — **CoffeeOps**. Среда — контейнер `bash:5` (на macOS системный bash — 3.2).

**Статус: ⚪ заготовка (репозиторий создан 11.10.2026). Методички нет, кода нет, ничего не проверялось запуском: есть только план [`bash_lab_plan.md`](bash_lab_plan.md).**

## Что по плану

- 9 сессий, ~36 часов, по ~4 часа каждая; в каждой — «Слова сессии», шаги по стандарту подробности («каждое слово объяснено», «где мы и что должно быть», «если не получилось»), «Сломать → починить», критерий приёмки.
- Режим: самостоятельная лаба, ничего проходить заранее не нужно.
- Версии и поведение инструментов в плане **не проверены прогоном**; пометки «сверьтесь» стоят там, где версия может измениться.
