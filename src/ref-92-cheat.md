# 1 · Шпаргалка: команды и конструкции | short: Шпаргалка | kind: ref
**Файлы и папки**

| Команда | Что делает |
|---|---|
| `pwd` | где я (текущая папка) |
| `ls -la` | список, включая скрытые, с правами |
| `cd папка`, `cd ..`, `cd -`, `cd` | войти, вверх, назад, домой |
| `mkdir -p a/b/c` | создать папки цепочкой |
| `touch f`, `cp a b`, `mv a b`, `rm f` | создать пустой файл, копировать, переместить/переименовать, удалить |
| `cat f`, `head -n 5 f`, `tail -n 5 f`, `wc -l f` | показать, первые, последние, посчитать строки |
| `chmod +x f`, `chmod 640 f` | сделать исполняемым, задать права цифрами |
| `type cmd`, `command -v cmd`, `help cmd` | что это за команда, где она, справка по встроенной |

**Скрипты и переменные**

| Конструкция | Что значит |
|---|---|
| `#!/usr/bin/env bash` | первая строка скрипта |
| `x=5`, `"$x"`, `${x}` | присвоить (без пробелов!), прочитать, выделить имя |
| `${1:-по умолчанию}`, `${1:?сообщение}` | значение по умолчанию, обязательный аргумент |
| `$0 $1 $@ $# $?` | имя скрипта, первый аргумент, все аргументы, их число, код последней команды |
| `$(cmd)`, `$((2+3))` | вывод команды, арифметика |
| `'…'` / `"…"` | всё буквально / переменные раскрываются |

**Условия и циклы**

| Конструкция | Что значит |
|---|---|
| `[[ -f f ]]`, `[[ -d d ]]`, `[[ -z "$x" ]]` | файл есть, папка есть, строка пустая |
| `(( a > b ))` | сравнение чисел |
| `[[ "$a" == b* ]]`, `[[ $a =~ ^[0-9]+$ ]]` | шаблон, регулярное выражение |
| `if …; then …; elif …; else …; fi` | ветвление |
| `case "$x" in a) …;; *) …;; esac` | выбор по шаблону |
| `for f in *.csv; do …; done` | цикл по списку |
| `while IFS= read -r line; do …; done < f` | цикл по строкам файла |
| `set -euo pipefail` | строгий режим |
| `trap 'cleanup' EXIT` | выполнить при выходе |

**Потоки**

| Конструкция | Что значит |
|---|---|
| `> f`, `>> f`, `< f` | записать, дописать, читать из файла |
| `2> f`, `2>&1`, `&> f` | ошибки в файл, ошибки туда же, куда вывод, всё в файл |
| `cmd1 \| cmd2` | вывод первой — ввод второй |
| `/dev/null` | «чёрная дыра» |
| `cmd <<'EOF' … EOF` | многострочный ввод |
| `xargs -n1 cmd`, `find … -print0 \| xargs -0 …` | применить команду к каждому элементу |

**Текст**

| Команда | Что делает |
|---|---|
| `grep -E 'a\|b' f` | искать строки (расширенные регулярки) |
| `sed 's/старое/новое/g' f` | заменить в потоке |
| `awk -F, '{print $2}' f` | вывести второе поле |
| `sort \| uniq -c \| sort -rn` | посчитать повторы и показать частые |
