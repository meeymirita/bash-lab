shell (оболочка) :: программа, которая принимает команды, которые ты набираешь, и просит систему их выполнить; bash, zsh, sh — разные оболочки
bash :: самая распространённая оболочка в Linux; название — «Bourne Again SHell»
терминал :: окно, в котором ты вводишь текст и видишь ответ; он показывает оболочку, но сам ею не является
процесс :: запущенная программа; у каждого процесса есть номер — PID
PID :: числовой номер процесса, по нему его можно найти и остановить
переменная окружения :: именованное значение, которое процесс передаёт своим «детям» (например, <code>PATH</code>, <code>HOME</code>)
PATH :: список папок, в которых оболочка ищет команды, когда ты вводишь имя без пути
права доступа :: кто (владелец, группа, остальные) и что (читать, писать, выполнять) может делать с файлом
shebang :: первая строка скрипта <code>#!/usr/bin/env bash</code>: указывает, какой программой запускать файл
позиционные параметры :: аргументы, переданные скрипту или функции: <code>$1</code>, <code>$2</code>, ...
код завершения :: число от 0 до 255, которое возвращает любая команда: 0 — успех, остальное — ошибка
подстановка команды :: <code>$(команда)</code> — вывод команды подставляется в строку
раскрытие (globbing) :: замена шаблона <code>*.csv</code> на список подходящих файлов — делает оболочка до запуска команды
stdin / stdout / stderr :: три стандартных потока процесса: ввод (0), вывод (1), вывод ошибок (2)
перенаправление :: направление потока в файл или из файла: <code>&gt;</code>, <code>&gt;&gt;</code>, <code>&lt;</code>, <code>2&gt;</code>
конвейер (pipe) :: <code>a | b</code> — вывод первой команды становится вводом второй
here-doc :: многострочный текст прямо в скрипте: <code>&lt;&lt;EOF ... EOF</code>
функция :: именованный кусок скрипта, который можно вызывать много раз
область видимости :: где переменная «видна»; в функции <code>local</code> прячет переменную от остального скрипта
trap :: ловушка: команда, которая выполняется при сигнале или выходе из скрипта
сигнал :: короткое сообщение процессу от системы или пользователя (<code>SIGINT</code> — Ctrl+C, <code>SIGTERM</code> — «завершись»)
массив :: переменная с несколькими значениями; индексный (по номеру) или ассоциативный (по ключу)
регулярное выражение :: шаблон для поиска текста: «три цифры подряд», «строка начинается с ERROR»
поле / запись (awk) :: запись — строка, поле — слово в ней, разделённое пробелом или заданным символом
идемпотентность :: свойство скрипта: повторный запуск даёт тот же результат и ничего не ломает
dry-run :: «сухой запуск»: скрипт печатает, что сделал бы, но ничего не меняет
cron :: планировщик: запускает команды по расписанию
контейнер :: изолированное окружение со своими файлами и программами, запускается из образа
образ :: «слепок» окружения, из которого запускаются контейнеры
