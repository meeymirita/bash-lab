# Сессия 10 · Итоговое задание

## 10.1 Задание: подкоманда `coffeeops.sh digest` | short: Итоговое ТЗ | est: ~2 ч
### intro
**Слова шага:** *техническое задание (ТЗ)*, *приёмка*, *самопроверка*.

Это сессия без новой теории: ты сама делаешь новую часть CoffeeOps по описанию, используя то, что уже прошла. Готового решения здесь нет, и так задумано: смотри свои скрипты из сессий 2–9, `man` и справочные страницы лабы.

**Задача.** Владелица кофейни хочет каждое утро получать короткую сводку о вчерашнем дне. Добавь в `coffeeops.sh` подкоманду `digest`, которая печатает такую сводку по файлам заказов и журналу.

**Как вызывать:**

```text
coffeeops.sh digest [-d ДАТА] [-o ФАЙЛ] [-q]
```

- `-d ДАТА` — день в формате `2026-10-02`; без опции берётся последний день в папке `orders/`.
- `-o ФАЙЛ` — записать сводку в файл (иначе печатать на экран).
- `-q` — тихий режим: только итоговая строка.
- `-h` — справка; неизвестная опция — ошибка с кодом 2.

**Что должна содержать сводка:**

1. Число заказов и выручка за день (`qty * price`).
2. Топ-3 товара по числу порций.
3. Число строк журнала `logs/app.log` с уровнем `WARN` и `ERROR` за этот день.
4. Строка «лучший час» — час с наибольшей выручкой.

**Требования к самому скрипту:**

- Файл `bin/digest.sh`, строгий режим (`set -euo pipefail`), функции и общая библиотека `lib/common.sh` (`log`, `die`).
- Опции разбирает `getopts`; значения в кавычках.
- Если файла за нужную дату нет, скрипт говорит понятное сообщение в `stderr` и выходит с кодом 2.
- Временные файлы (если нужны) создаются через `mktemp` и удаляются через `trap`.
- Для подсчётов используй то, что прошла: конвейеры, `awk`, `sort | uniq -c`, ассоциативный массив, `grep`.
- Подкоманда подключена в `case` у `coffeeops.sh` и в `usage`.
- Скрипт проходит `shellcheck` без замечаний.
- Добавлены минимум два теста в `tests/run.sh`: успешный запуск и ошибка при несуществующей дате.

**Чего не требуется:** красивого оформления, цветов, отправки сводки по почте. Главное, чтобы цифры были правильными и скрипт вёл себя предсказуемо.

**Порядок работы (подсказка, не решение):** сначала посчитай нужные числа обычными командами в консоли, потом оберни в функции, потом добавь разбор опций, в конце тесты и `shellcheck`.

### why
Прочитать готовый шаг и написать скрипт по описанию — разные навыки. Здесь ты собираешь вместе всё пройденное: опции, функции, потоки, текстовые утилиты, ошибки, тесты. Если застряла, значит, нашла тему, к которой стоит вернуться.

### quiz
Проверь себя: выполнено ли задание?
- `./bin/coffeeops.sh digest` печатает сводку из четырёх частей за последний день.
- `-d 2026-10-02`, `-o файл`, `-q`, `-h` работают, неизвестная опция даёт код 2.
- Несуществующая дата даёт сообщение в `stderr` и код 2.
- Цифры совпадают с тем, что ты насчитала вручную для одного дня.
- `shellcheck bin/*.sh lib/*.sh tests/*.sh` не находит замечаний.
- `./bin/coffeeops.sh test` проходит, в нём есть минимум два новых теста.
- Временных файлов после запуска не остаётся, в том числе при прерывании по [[Ctrl]]+[[C]].
