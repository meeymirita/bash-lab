# 3 · Справочник ошибок: симптом → причина → что делать | short: Справочник ошибок | kind: ref
| Симптом | Причина | Что делать |
|---|---|---|
| `command not found` | нет такой команды в `PATH`, опечатка, или скрипт запущен без `./` | проверь написание; `type имя`; для своего скрипта — `./имя` |
| `Permission denied` | нет права `x` у файла (или `w`/`r` у папки) | `chmod +x файл`; `ls -l` |
| `bad interpreter: No such file or directory` | в shebang указан интерпретатор, которого нет (`/bin/bash`) | первая строка `#!/usr/bin/env bash` |
| `No such file or directory` | неверный путь, опечатка, другая папка | `pwd`, `ls`; проверь регистр и пробелы |
| `x = 5: command not found` | пробелы вокруг `=` в присваивании | `x=5` без пробелов |
| `unbound variable` | включён `set -u`, переменная не задана | задай значение или `${x:-}`; проверь опечатку |
| `syntax error near unexpected token 'done'` | пропущен `do`, `then`, `;` или перевод строки | сверь форму конструкции; `bash -n скрипт` |
| `syntax error: unexpected end of file` | не закрыта кавычка, `if` без `fi`, `case` без `esac` | найди парную конструкцию |
| `unexpected EOF while looking for matching '"'` | незакрытая кавычка | проверь парность `"` и `'` |
| `integer expression expected` | `[ ]` с `-eq`/`-gt`, а в переменной не число | проверь значение: `[[ $x =~ ^[0-9]+$ ]]` |
| `unary operator expected` | пустая переменная без кавычек в `[ ]` | `[[ … ]]` или `"$x"` |
| `bad substitution` | неверная форма `${…}` или старый bash (`^^`, `declare -A`) | проверь скобки; `echo $BASH_VERSION` |
| `arithmetic syntax error` / `invalid arithmetic operator` | в `$(( ))` не число или дробь | проверь значения; дроби считай через `awk` |
| `ambiguous redirect` | в имени файла для `>` пустая переменная или слова | `> "$файл"` и проверь переменную |
| `Is a directory` | вместо файла указана папка | уточни путь |
| `rm: cannot remove 'x': Is a directory` | для папок нужен `-r` | `rm -r` (после `ls`!) |
| `cd: too many arguments` | пробел в имени папки без кавычек | `cd "моя папка"` |
| `ls: cannot access '*.csv'` | в папке нет подходящих файлов (шаблон остался буквально) | `shopt -s nullglob` или `[[ -e "$f" ]] \|\| continue` |
| `grep` «ничего не вывел» и код 1 | совпадений нет (это не ошибка) | при `set -e` — `grep … \|\| true` |
| скрипт остановился «без причины» | `set -e` и команда вернула ненулевой код | `bash -x скрипт` покажет, где |
| `$x` пуст после цикла `\| while` | конвейер запустил цикл в подпроцессе | `while … done < <(команда)` |
| файл стал пустым после `sort f > f` | `>` обнуляет файл раньше чтения | запись во временный файл, затем `mv` |
| имя файла с пробелом «рассыпалось» | переменная или `$(ls)` без кавычек | `"$f"`, шаблон вместо `ls` |
| `sed: unterminated 's' command` | не закрыт `s///` или `/` внутри текста | другой разделитель: `s\|a\|b\|` |
| `sed -i` не работает на Mac | BSD sed требует суффикс после `-i` | `sed -i.bak …` (работает везде) |
| `mapfile: command not found` / `declare: -A: invalid option` | bash старше 4 (Mac: 3.2) | запускай в контейнере с bash 5 |
| `crontab`-задание не работает | пустое окружение, относительные пути, вывод в никуда | полные пути, `>> журнал 2>&1` |
| `awk` вывел лишний заголовок | `NR > 1` пропускает только первый файл | `FNR > 1` для нескольких файлов |
| `Cannot connect to the Docker daemon` | Docker Desktop не запущен | открой приложение, дождись значка |
| результат `shellcheck` «Not following» | не найден файл в `source` | `.shellcheckrc`: `source-path=SCRIPTDIR`; `shellcheck -x` |
